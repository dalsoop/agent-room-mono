# AgentRoomTerminal (GUI)

## 범위

트리 캔버스(CALayer 노드 트리·직교 간선·팬·줌), 상세 단계 L0/L1/L2 와 SwiftTerm `TerminalView` 오버레이, 노드 헤더(예산 게이지·프리셋·미준수 칩·약한 벽·빈병 사슬·공존 입주자), 상세 패널, 컨텍스트 메뉴, 설정 화면(튜닝값 7개 + 순정 원복), 온보딩(사용법 소개), 프레임 측정.

## 범위 밖

배치·LOD 계산(코어 Canvas 의 순수 함수), 도메인 판단(코어), 터미널 파싱(데몬), 원장·정책 직접 접근.

## 불변식

- 컨텍스트 메뉴의 열기·닫기·핸드오프·시뮬레이션·습관은 `RoomActions` 구현을 통해 코어의 같은 진입점을 부른다(CLI 와 동일 경로). 부작용 액션 앞에는 확인 시트가 한 번 뜬다.
- 배치는 원장 변경 이벤트에서만 다시 계산한다. 팬·줌은 `CATransform3D` 만 바꾼다.
- L2 는 뷰포트 안 + 화면 중앙에서 가까운 순으로 `liveTerminalCap`(기본 8)까지. 넘치면 먼 것부터 L1.
- PTY 출력 수신은 백그라운드 큐, 뷰 갱신만 메인 스레드. L2 는 더티 행만 30Hz 이하, L1 은 2Hz.
- 뷰포트 밖 200pt 너머 레이어는 `isHidden`.
- 원장이 비어 있으면 픽스처 50방 트리를 "예시" 표시와 함께 그린다. 픽스처는 실제 데이터로 오해되지 않게 표시가 항상 보인다.
- 문안은 L10n 키로만. 「잠자기」.

## 패턴

`CanvasView`(NSView) 가 레이어 트리를 소유하고 `NodeLayer` 가 노드 하나를 그린다. `TerminalOverlay` 는 L2 노드 위에 NSView 로 얹힌다. `PerformanceMeter` 가 프레임 시간을 모아 p95 를 낸다.

## 테스트

순수 계산은 코어 테스트(배치 시간·겹침·LOD). GUI 는 빌드 + 실행 확인(`agent-ui-monitor see --app AgentRoomTerminal --compact` 로 노드 수와 상단 표시 확인). 화면을 바꾸면 프레임 p95 를 다시 적는다.
