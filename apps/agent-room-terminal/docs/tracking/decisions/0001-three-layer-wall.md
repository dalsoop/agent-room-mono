# 0001 — 벽은 세 겹, 훅은 보조

**상황**: 방에 앉은 세션이 허용 밖 명령을 치는 것을 막아야 한다. 이전 방 체제는 배치도 제출 때 toolbelt 만 검사했고 실행 시점에는 아무 벽이 없었다. 훅은 Claude Code 에만 있고 Codex·Antigravity 에는 없다.

**결정**: 제한 셸(`zsh -r`) + 방 `bin/` 전용 PATH + seatbelt 파일 샌드박스 세 겹을 주 벽으로 하고, 훅 `check` 는 절대경로 우회 같은 잔여를 잡는 보조로 둔다. 기본 셸 폴더에 python3 을 넣지 않는다.

**대안**: (a) PATH + 훅만 — 훅 없는 도구에서는 벽이 없다. (b) 샌드박스만 — 명령 실행은 못 막고 파일 쓰기만 막는다. (c) 벽 없이 리뷰로 — 사고 뒤에 안다.

**결과**: 도구에 상관없이 같은 벽이 선다. 대신 방 안에서 스크립트가 필요하면 소유 앱에 명령을 추가해야 하고, 개방(open) 프리셋은 명시적으로만 열린다. 훅만으로 앉은 세션은 "약한 벽" 으로 표시된다.
