# 0002 — 자식은 별도 프로세스만

**상황**: Claude Code 의 서브에이전트 도구는 같은 프로세스·같은 env·같은 cwd 로 돈다. 방 폴더·PATH·샌드박스를 받을 수 없어 벽이 서지 않는다.

**결정**: 자식 방의 에이전트는 자식 방 터미널에서 별도 프로세스(`claude -p`·codex 등을 자식 방 세션 셸에서)로만 띄운다. 방 안에서 서브에이전트 도구 호출은 훅이 거부한다. 자식이 부모에게 돌려줄 수 있는 것은 원장 상태 전이와 빈병 파일뿐이다.

**대안**: (a) 서브에이전트도 허용하되 부모 벽만 적용 — 자식만의 좁은 벽이 없고 조사 에이전트가 방 밖 파일을 읽는다. (b) 프로세스 간 파이프로 결과 회수 — 단방향 결속이 깨진다.

**결과**: 자식 하나가 프로세스 하나라 동시 방 수가 프로세스 수를 정한다(라이브 방 30개 안팎). 부모는 자식의 출력을 스냅샷과 빈병으로만 본다.
