# 0004 — 핸드오프는 워커가 결정, 전임은 통과까지 생존

**상황**: 컨텍스트가 압축되기 전에 세대를 교체해야 한다. 누가 빈병을 명령하는지, 교체 중 한 방에 둘이 있어도 되는지가 열려 있었다.

**결정**: 훅이 매 턴 예산을 읽어 handoff-due 를 알리고 워커 세션이 스스로 `handoff` 를 친다. 지휘실은 빈병 교체가 2회를 넘을 때만 게이트를 연다. 후임의 시뮬레이션이 통과할 때까지 전임은 살아 있고, 원장 방에 공존 필드(successorOccupant·successorSession·handoverState)를 둔다. 토큰과 체류 시간 둘 다 신호다.

**대안**: (a) 지휘실이 명령 — 워커 상태를 지휘실이 다 알 수 없어 늦다. (b) 전임 즉시 퇴거 — 재연 실패 시 되돌릴 사람이 없다. 원장 스키마는 단순하지만 빈병 보강 경로가 없다.

**결과**: 공존 중 자리와 예산이 이중 계상된다. 재연 실패의 반려 대상은 빈병이며 전임이 보강한다.
